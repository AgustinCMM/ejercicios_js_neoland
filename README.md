# Ejercicios de HTML, CSS y JavaScript · Clase 5

25 misiones para practicar, organizadas en cinco categorías. Cada ejercicio tiene su propia carpeta con los archivos ya vinculados y la consigna visible dentro del HTML.

## Cómo usar este entorno

1. Abre index.html en el navegador para ver el menú de misiones.
2. Entra en la misión que quieras practicar.
3. Escribe tu solución en js/script.js.
4. Si la misión necesita estilos propios, usa css/styles.css.
5. Recarga la página con F5 después de cada cambio.
6. Abre “Pista de detective” solo si necesitas una ayuda.

> No hay soluciones escritas: el código JavaScript de cada ejercicio está vacío a propósito.

Cada carpeta de ejercicio contiene:

```
numero-nombre-del-ejercicio/

├── css/
│   └── styles.css  → estilos propios del ejercicio
└── js/
    └── script.js   → aquí escribes tu solución
```
