La paleta del pintor

El reto: En HTML existe una etiqueta especial para elegir colores. Ponla en tu página junto con una caja grande y vacía (un div que será tu lienzo). Cada vez que elijas un color nuevo, la caja grande debe pintarse de ese color.

El selector de color y el lienzo ya están creados. El selector arranca con el color #3f6f9c y el lienzo está vacío.

🕵️ Pista de detective

Para el HTML, busca <input type="color">. Para el JS, recuerda que las cajas de input guardan su información en una propiedad llamada value. ¡Usa un evento diferente al clic (busca el evento input o change) para robar ese color y ponérselo al fondo de tu caja!
